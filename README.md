Projeto Integrador - Sistema de Reserva de Assentos de Cinema

# 🎬 Sistema de Reserva de Assentos de Cinema

Projeto Integrador desenvolvido para a disciplina **Boas Práticas de Desenvolvimento de Software**, com o objetivo de aplicar conceitos de organização, desenvolvimento colaborativo e boas práticas na criação de uma aplicação web simples, responsiva e funcional.

O projeto simula o processo de reserva de ingressos de cinema, permitindo ao usuário selecionar um filme, escolher o horário da sessão, visualizar e selecionar poltronas, acompanhar o valor da reserva e finalizar o processo através de uma simulação de pagamento.

## 📌 Sobre o projeto

O **Sistema de Reserva de Assentos de Cinema** foi desenvolvido como uma aplicação web acadêmica, simulando uma experiência de compra e reserva semelhante à encontrada em plataformas de cinema.

O sistema permite que o usuário percorra diferentes etapas, desde a escolha do filme até a confirmação da reserva.

O projeto foi desenvolvido de forma colaborativa por uma equipe de **8 integrantes**, com divisão das responsabilidades por etapa do desenvolvimento.

---

## 🎯 Objetivo

Desenvolver uma aplicação web simples e interativa capaz de simular o processo de reserva de ingressos de cinema.

Durante a utilização do sistema, o usuário pode:

- visualizar os filmes disponíveis;
- escolher um filme;
- selecionar o horário da sessão;
- visualizar a disposição das poltronas;
- identificar assentos disponíveis e ocupados;
- selecionar e desmarcar poltronas;
- visualizar a quantidade de lugares selecionados;
- acompanhar o cálculo do valor da reserva;
- avançar para uma etapa de pagamento simulado;
- receber a confirmação da reserva.

---

## ✨ Funcionalidades

### 🎥 Seleção de filmes e horários

Na página inicial, o usuário pode visualizar as opções de filmes disponíveis e selecionar o filme e o horário desejados.

---

### 💺 Seleção de assentos

A aplicação apresenta visualmente a disposição das poltronas da sala.

Os assentos possuem diferentes estados, permitindo identificar:

- assentos disponíveis;
- assentos selecionados;
- assentos ocupados.

O usuário pode selecionar ou desmarcar os lugares disponíveis antes de prosseguir.

---

### 💰 Cálculo da reserva

Durante a seleção das poltronas, o sistema atualiza as informações relacionadas à reserva de acordo com as escolhas realizadas pelo usuário.

---

### 💳 Simulação de pagamento

O projeto possui uma etapa de pagamento desenvolvida exclusivamente para fins acadêmicos.

As opções apresentadas fazem parte apenas da simulação do fluxo da aplicação.

> **Não existe processamento financeiro, integração bancária ou realização de pagamentos reais.**

---

### 🎟️ Confirmação da reserva

Após a conclusão das etapas anteriores, o usuário é direcionado para uma tela de confirmação com as informações da reserva.

---

### 💾 Armazenamento local

A aplicação utiliza o **LocalStorage** do navegador para armazenar informações durante a navegação entre as páginas.

Dessa forma, o projeto não necessita de banco de dados externo.

---

### 📱 Responsividade

A interface possui adaptações para diferentes tamanhos de tela, permitindo a utilização da aplicação também em dispositivos móveis.
