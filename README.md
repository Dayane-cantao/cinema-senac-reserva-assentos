# Sistema Simples de Reserva de Assentos de Cinema

Projeto Integrador da disciplina Boas Práticas de Desenvolvimento de Software.

## Objetivo

Desenvolver uma aplicação web simples e interativa para simular a reserva de ingressos de cinema.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
